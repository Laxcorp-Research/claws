Impl: Components: ApiKeyModal. Reused for all API key connections (Apollo, Instantly, Tavily, Binance, etc.). Props: toolName, toolSlug, helpUrl, placeholderFormat. On submit: POST to /api/tools/[workspaceId]/connect which validates, encrypts (AES-256-GCM), stores in ToolConnection model. Shows spinner during validation, success/error after.

Modal — Connect custom API
For niche tools not in Composio's catalog. User provides base URL and credentials.
Connect a custom API
Add any API not available in our catalog. Your agents will be able to make HTTP requests to this service.
Impl: Components: CustomApiModal. On submit: POST to /api/tools/[workspaceId]/custom. Tests connectivity (HEAD request to base URL). Encrypts credentials. Creates CustomToolConnection record. Auto-generates a SKILL.md template for this API that agents will read.
Modal — Confirmation dialogs
Used for destructive actions: deleting a Claw, pausing all agents, removing a tool connection.

⚠ If this Claw is currently deployed, the container will be stopped and removed.
Pause all agents?
This will pause the "B2B Sales Machine" container. Agents will stop running until you resume. Pending tasks will be queued.
Impl: Components: ConfirmDialog (reusable). Props: title, description, confirmLabel, confirmVariant (danger/warning/default), onConfirm, onCancel. Used for: delete workspace, pause/resume, remove tool connection, disconnect channel.
